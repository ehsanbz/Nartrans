# NAR TRANS website

An original static design inspired by the chosen Logis direction, using the supplied NAR TRANS logo. Official company name: Nar international srl. No third-party template code is included.

## GitHub Pages

Upload index.html, assets/, CNAME and .nojekyll to the repository root. In repository Settings → Pages, select Deploy from a branch and the main branch root. Set the custom domain to www.nartrans.eu and enable HTTPS when available.

In your domain provider's DNS settings, create a CNAME record for www pointing to YOUR-GITHUB-USERNAME.github.io (without the repository name). Follow GitHub's current custom domain documentation for the root nartrans.eu domain and domain verification: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site

The website uses email links; the quotation button opens the visitor's email application with suggested shipment fields. No backend or form service is required.
